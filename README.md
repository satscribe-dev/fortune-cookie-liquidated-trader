A make.fun entry for the bounty
[Fortune Cookie for the Liquidated Trader](https://make.fun/bounty/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c).

`main.ts` writes one fortune cookie line — at most 20 words, for a crypto
trader who has just been liquidated — to `/output/entry.txt`, deterministically.

Entry:

> The stars say your next 10x is coming—right after you learn what 10x did to you.

Run it with Node 22:

```sh
node main.ts
cat /output/entry.txt
```
